# Web comercial de DuCare

Web estática (HTML+CSS, sin JS ni cookies). Desplegar como **proyecto Vercel aparte** con *Root Directory* = `web` y sin build.

Pendiente (lo aporta el usuario):
- Dominio: sustituir `https://www.ducare.es` (canonical, OG, robots, sitemap) por el real.
- Rellenar los `[RAZÓN SOCIAL]`, `[NIF]`, `[DIRECCIÓN]`, `[EMAIL DE CONTACTO]` (marcados en amarillo) y el `mailto:` de la demo. Sin nombre personal: usar razón social o marca.
- `og.png` (1200×630) y logo/colores definitivos.
